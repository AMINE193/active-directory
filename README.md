# Laboratorio de Active Directory

Proyecto de portfolio orientado a la administración de sistemas y al soporte IT.

## Objetivo

Diseñar, desplegar y documentar una infraestructura virtual que simule el entorno informático de una pequeña empresa mediante Windows Server y Active Directory.

## Estado

🟡 En planificación.

## Tecnologías previstas

- Windows Server
- Active Directory Domain Services (AD DS)
- DNS y DHCP
- Directivas de grupo (GPO)
- Windows cliente
- VirtualBox o VMware
- PowerShell

## Contenidos previstos

- Diseño y topología de red
- Instalación del controlador de dominio
- Creación de usuarios, grupos y unidades organizativas
- Gestión de permisos y carpetas compartidas
- Aplicación de políticas GPO
- Automatización básica con PowerShell
- Registro y resolución de incidencias
- Capturas y conclusiones

## Metodología

El proyecto se desarrollará por fases. Cada avance incluirá su objetivo, procedimiento, evidencias, problemas encontrados y solución aplicada.

> Este repositorio no contendrá contraseñas, claves, datos personales reales ni información sensible.
